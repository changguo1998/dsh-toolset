- **命令 / 路径类拒绝规则**：危险命令与敏感路径归 `security-guard`（唯一最终否决者，R3）；本包拒绝名单只表达「不自动批」。
- **按会话配置**：会话级旋钮由宿主 `/policy` 与 `/permission` 承担，本包跟随生效。
- **巡检工具（从会话日志还原自动放行）**：可选增量，首期不做（设计「收尾动作」遗留项）。
