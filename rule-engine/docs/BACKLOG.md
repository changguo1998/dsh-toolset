  - 现象 / 现状: 用户级规则库 `~/.dsh/rule-engine/rules.json` 里只有一条规则 —— `id: e2e-rule`, `enabled: true`, `sources: ["assistant-text"]`, `delivery: "followup"`, `match.keywords: ["端到端"]`, `action: inject` 固定文案, 且 `cooldownTurns: 0` / `cooldownMs: 0` / `dedupeInRecord: 0` / `description: null`。实际效果: 助手正文只要出现该关键词, 宿主就追加一条 followup 注入; 因冷却与去重都是 0, 同一回合内反复提到就反复触发 —— 2026-11-08 实测连触三次, 把正常对话打断。该文件在项目目录之外, 属用户配置面, 不是本仓代码。
