# 术语表

- 管什么：现行文档与新文档的术语选择与替换。
- 不管什么：代码标识符、包名本身（包名不改）、宿主接口术语与归档改写。
- 何时失效：`AGENTS.md` 的术语规则或宿主术语变更时复核。

## 场景 → 应当使用

| 场景 | 应当使用 | 说明 |
| --- | --- | --- |
| 指一个包（代码模块） | 包 | 「模块」只在指层次时保留；不再用「插件包」泛指 |
| 数插件 | 插件 | 本仓 34 个包 = TUI 与 33 个插件 |
| 指行为变差 | 退化 | 不写「回归」 |
| 指重跑旧用例确认没破坏旧行为 | 守成测试 | 不写「回归测试」 |
| 存储位置 | 存放位置 / 存储路径 | 不写「落点」 |
| 审计 | 审计双写 | 不写「落点」 |
| 实现位置 | 实现位置 | 不写「落点」 |
| 投递 | 投递目标 | 不写「落点」 |
| 文档改动位置 | 改动位置 | 不写「落点」 |
| 完成主要任务后、结束前的剩余琐事 | 收尾 | 统一格式写「统一」、集中位置写「集中」、两者兼有写「统合」 |
| 会话界面 | 活动区 / 输入区 / 状态列 / 提示行 | 不写回合区 / 对话区 / 输入框 / 状态栏 / 底部提示 |
| 模型可见的工具面 | 工具面 | 项目自称用「插件集」，`docs/host` 的宿主快照保留 |
| 决策项 | 决策项 | 不写「决策点」（`docs/host` 除外） |
| 审阅 | 审阅 | 不写「评审」 |
| 回执 | 回执 | 不写「返回体」 |
| `surfaceOp: replace` 的情况 | 更正事件 | 不写「影子覆盖事件」 |

## 需要替换

| 需要替换 | 应当使用 | 条件与例外 |
| --- | --- | --- |
| 模块 | 包 | 与包并列指层次时保留「模块」；「模块 = TUI 与 N 个包」改「本仓 34 个包 = TUI 与 33 个插件」 |
| 插件包 | 包 / 插件 | 泛指代码模块用「包」，数插件用「插件」 |
| 过程记录 | 追踪文档 | 归档不改 |
| 符号规则 | 符号规范 | - |
| 工具集 | 工具面 / 插件集 | 模型可见工具面用「工具面」，项目自称用「插件集」；`docs/host` 保留 |
| 决策点 | 决策项 | `docs/host` 除外 |
| 评审 | 审阅 | 命令模板的中文活动名同改；模板文件名与 slash 命令名不变 |
| 返回体 | 回执 | - |
| 回归 | 退化 / 守成测试 | 指行为变差用「退化」，指测试用「守成测试」 |
| 收口 | 统一 / 集中 / 统合 / 收尾 | 统一格式用「统一」，集中位置用「集中」，两者兼有用「统合」，收尾琐事用「收尾」 |
| 落点 | 见场景表 | 按存储 / 审计 / 实现 / 投递 / 文档 / 条目分写 |
| 影子覆盖事件 | 更正事件 | `surfaceOp: replace` 的情况 |
| 回合区 / 对话区 | 活动区 | 历史对照句可注「原名」 |
| 输入框 | 输入区 | 历史对照句可注「原名」 |
| 状态栏 | 状态列 | 历史对照句可注「原名」 |
| 底部提示 | 提示行 | 历史对照句可注「原名」 |

## 保留

| 术语 | 处理 | 原因 |
| --- | --- | --- |
| 兜底 / 落盘 / 服务面 / 事件面 / 挂载 / 冒烟 / 灰区 / 旁路 / 骨架 | 保留 | 已成固定说法，替换只会增加理解成本 |
| 工具集 / 影子表 | 保留 | 只用于 `docs/host` 的宿主快照与结论 |
| intercom / knowledge-base / herdr-pane / timer | 保留 | 旧包名，只在首次出现处写「原名 `x`」 |
| 命令模板文件名与 slash 命令名 | 保留 | 如 `adversarial-review` / `code-review`，与中文活动名分开 |
