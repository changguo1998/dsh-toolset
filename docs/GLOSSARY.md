# 术语表

- 管什么：现行文档与新文档的术语选择与替换。
- 不管什么：代码标识符、包名本身（包名不改）、宿主接口术语与归档改写。
- 何时失效：`AGENTS.md` 的术语规则或宿主术语变更时复核。

## 推荐术语

| 推荐术语 | 解释 |
| --- | --- |
| 包 | 指一个代码模块 |
| 插件 | 数插件用；本仓 37 个包 = TUI 与 36 个插件 |
| 退化 | 指行为变差 |
| 守成测试 | 指重跑旧用例确认没破坏旧行为 |
| 追踪文档 | 指过程记录 |
| 符号规范 | 指符号规则 |
| 工具面 | 指模型可见的工具面 |
| 用户面 | 指与用户交互的能力面: TUI 界面与 slash 命令 |
| 界面 | 只指需要用 TUI 交互的内容 (下面七个界面名称), 不含 slash 命令 |
| 服务面 | 指进程内 cordis 服务, 供其他插件读取 |
| 事件面 | 指宿主事件钩子: `session/event`, `agent/pre-step` 等 |
| 注册面 | 指注册能力: `tools` 注册表, rule-engine 的消费者登记 |
| 宿主面 | 指官方 dsh 包与其接口, 研读记录在 `docs/host/` |
| 审计双写 | 指审计 |
| 决策项 | 指决策项 |
| 审阅 | 指审阅 |
| 回执 | 指回执 |
| 更正事件 | 指 `surfaceOp: replace` 的情况 |
| 存放位置 / 存储路径 | 指存储位置 |
| 实现位置 | 指实现位置 |
| 投递目标 | 指投递 |
| 改动位置 | 指文档改动位置、BACKLOG 条目 |
| 收尾 | 指完成主要任务后、结束前的剩余琐事；统一格式写「统一」、集中位置写「集中」、两者兼有写「统合」 |
| 状态列 | 界面名称：顶部左侧常驻纵向状态列，承载 Goal / Todo / Jobs / Agents |
| 会话区 | 界面名称：展示历史消息的 pane，含标题栏与历史流 |
| 回合区 | 界面名称：展示当前回合流式内容的 pane |
| 工具区 | 界面名称：回合区内按需显示交互面板的窗口（审批 / 问答 / 模型选择 / 列表族） |
| 状态行 | 界面名称：输入区上方的横向系统状态行 |
| 输入区 | 界面名称：底部输入框区域 |
| 提示行 | 界面名称：底部按键提示行 |

界面名称只用上表七个（2026-11-02 用户裁定；`dev/standard` 的 `term.interface` 规则守护，旧称列表见「禁止术语」）。
`交互区` 是「输入区 + 提示行」的组合名，不再单独使用。
「界面」只指需要 TUI 交互的内容; slash 命令归「用户面」, 不算界面。

## 禁止术语

| 禁止术语 | 应当使用 | 条件与例外 |
| --- | --- | --- |
| 模块 | 包 | 与包并列指层次时保留「模块」；「模块 = TUI 与 N 个包」改「本仓 37 个包 = TUI 与 36 个插件」 |
| 插件包 | 包 / 插件 | 泛指代码模块用「包」，数插件用「插件」 |
| 过程记录 | 追踪文档 | 归档不改 |
| 符号规则 | 符号规范 | - |
| 工具集 | 工具面 / 插件集 | 模型可见工具面用「工具面」，项目自称用「插件集」；`docs/host` 保留 |
| 决策点 | 决策项 | `docs/host` 除外 |
| 评审 | 审阅 | 命令模板的中文活动名同改；模板文件名与 slash 命令名不变 |
| 返回体 | 回执 | - |
| 回归 | 退化 / 守成测试 | 指行为变差用「退化」，指测试用「守成测试」 |
| 收口 | 统一 / 集中 / 统合 / 收尾 | 统一格式用「统一」，集中位置用「集中」，两者兼有用「统合」，收尾琐事用「收尾」 |
| 落点 | 见「推荐术语」 | 按存储 / 审计 / 实现 / 投递 / 文档 / 条目分写 |
| 影子覆盖事件 | 更正事件 | `surfaceOp: replace` 的情况 |
| 活动区 / Turn 区 / Turn 面板 / 活动 pane | 回合区 | 归档不改; 历史对照句可注「原名」 |
| 对话区 / 历史区 / 对话历史区 / 历史 pane / 对话 pane | 会话区 | 归档不改; 历史对照句可注「原名」 |
| 系统状态区 / 系统状态栏 | 状态行 | 归档不改; 历史对照句可注「原名」 |
| Tool 面板区 / 工具面板区 / Tool 面板 / 工具面板 | 工具区 | 归档不改; 历史对照句可注「原名」 |
| 交互区 | 输入区 + 提示行 | 组合名拆开; 归档不改 |
| 输入框 / 输入栏 | 输入区 | 历史对照句可注「原名」 |
| 状态栏 | 状态列 / 状态行 | 按位置: 左侧竖列用「状态列」, 底部横条用「状态行」; 不再单独用「状态栏」 |
| 底部提示 / 提示区 | 提示行 | 归档不改; 历史对照句可注「原名」 |

## 保留

| 术语 | 处理 | 原因 |
| --- | --- | --- |
| 兜底 / 落盘 / 挂载 / 冒烟 / 灰区 / 旁路 / 骨架 | 保留 | 已成固定说法，替换只会增加理解成本 |
| 工具集 / 影子表 | 保留 | 只用于 `docs/host` 的宿主快照与结论 |
| intercom / knowledge-base / herdr-pane / timer | 保留 | 旧包名，只在首次出现处写「原名 `x`」 |
| 命令模板文件名与 slash 命令名 | 保留 | 如 `adversarial-review` / `code-review`，与中文活动名分开 |
