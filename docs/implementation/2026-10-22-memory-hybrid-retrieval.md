## 目标

把 `memory-base` 的检索从单语词面 FTS5 升级为**混合检索**：FTS5 BM25 权重 + 词项邻近（proximity）加分 + 多路结果融合（RRF），并允许调用方按策略取用。

交付：`memory_query` 等入口可指定策略（缺省保持现有行为）、固定查询与期望命中序的测试夹具、延迟不劣化的证据。

边界：不改存储 schema 与写入 / 巩固逻辑；不引入外部检索依赖；不改变无命中时的行为。
