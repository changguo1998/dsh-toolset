# 思考内容排版支持更多列表类型（接取条目：TUI/docs/BACKLOG.md「思考内容排版时支持更多的列表类型」）

状态：测试　　开启：2026-10-19　　关闭：
本文件是本任务唯一的过程记录与文档变更落点；计划外的文件不改。

## 目标

在思考与正文共用的 `wrapAssistantLine` 管线（`src/app/layout/markdown.ts`）上扩充列表分类，支持更多列表类型；补齐范围与嵌套深度开工时裁定（候选：有序 `1)` 分隔 / 字母编号 / 圆括号编号 / 嵌套层级缩进 / 有序任务列表 `1. [ ]` / 定义列表）；当前只认无序 `• ` 与有序 `\d+.`、任务列表只认无序前缀、无嵌套。

## 调研

（来源：源码 `TUI/src/app/layout/markdown.ts`、既有测试 `TUI/tests/layout4.test.ts`、既有规格 `TUI/docs/SPEC.md` §15.5）

1. **现有列表分类（`markdown.ts`）**：
   - `TASK_RE`（:784）`^\s*[-*+][ \t]+\[([ xX])\][ \t]+(.+)$` —— 仅无序前缀 `-/*/+`，无编号、无嵌套。
   - `LIST_RE`（:787）`^\s*(?:[-*+]+|\d+\.)[ \t]+(.+)$` —— 无序 `-/*/+`（渲染为 `• `）或有序 `\d+.`；前导空白未用于层级。
   - `assistantLineRows`（:849）：逐行独立分类（分隔线 → 任务 → 标题 → 引用 → 列表 → 行内），**无跨行状态**——每行孤立判定。
   - `wrapListRows`（:822）：单级悬挂缩进（`prefixWidth` 计入首行宽, 续行补 prefixWidth 空格对齐正文）。
2. **渲染口径**：列表前缀正常前景色, 正文走 `parseInlineMarkdown`（行内 md 与列表叠加已生效）；续行悬挂对齐正文、不顶满（`layout4.test.ts:1874-1920` 有长项折行与列宽断言）。
3. **思考与正文共用**：`wrapAssistantLine` 为两者同一管线, 扩展自动两侧一致（`layout4.test.ts:1837-1873` 思考同口径已有断言）。
4. **缺口**：`1)` / `a.` / `(1)` 等编号风格不识别（落入普通行内 md）；前导空格缩进不产生层级（`  - 子` 当顶级项渲染）。

## 决策

1. **补齐范围（用户 2026-10-20 裁定, 多选）**：① 编号风格 = 有序 `)` 分隔 / 字母（`a.` / `A.` / `a)`）/ 圆括号 `(1)`；② 嵌套层级缩进。**不包含**：有序任务列表（`1. [ ]`）、定义列表（`term`+`: def`）——后两者需跨行状态或新块类型, 超出本次范围。
2. **嵌套实现（用户裁定 a) 真层级）**：按行前导**缩进列数**定层级, 每 2 列 = 一层（`depth = floor(indentWidth / 2)`）；渲染时前缀前补 `depth * 2` 宽空格（与判定同口径），悬挂缩进 = `depth*2 + prefixWidth`（子层续行对齐该层正文起列）。逐行独立判定（沿用无跨行模型）：孤立缩进行也按自身深度渲染, 不做父子校验。
3. **编号前缀保留与归一**：`LIST_RE` 扩展匹配 `\d+(?:\.|\))|[a-zA-Z](?:\.|\))|(?:\(\d+\))`；无序仍统一 `• `；有序保留原文编号+分隔符（`1.` / `1)` / `a.` / `(1)` 原样）。
4. **与行内 markdown 叠加**：维持现状——前缀后正文继续 `parseInlineMarkdown`。
5. **测试与口径同步**：新增布局断言覆盖各编号风格渲染、两级嵌套缩进、嵌套内长项悬挂折行；思考与正文同口径沿用双轨用例；`SPEC.md` §15.5 更新。

## 实现记录

改动落在 `TUI/src/app/layout/markdown.ts`（思考与正文共用管线, 改动自动两侧生效）：

- `TASK_RE`（:783）扩展捕获组：①前导缩进（嵌套层级用）②标记 ③勾选态 `[ xX]` ④正文。
- `LIST_RE`（:787）扩展匹配无序 `-` / `*` / `+` 与有序 `1.` / `1)` / `a.` / `a)` / `(1)`；捕获 ①前导缩进 ②完整前缀（含尾随空白）③正文。
- 新增 `listDepthOf`（:790）：`Math.floor(displayWidth(indent) / 2)`，每 2 列 = 一层（与决策 2 同口径）。
- 任务列表分支（:863 起）：前缀 = `"  ".repeat(listDepthOf(indent))` + `[x] `（已完成，正文删除线）/ `[ ] `（未完成）；勾选渲染与悬挂折行沿用既有 `wrapListRows`。
- 普通列表分支（:907 起）：无序统一 `• `；有序保留原文编号 + 分隔符（`marker` 去尾随空白后补单空格, 如 `1.` / `1)` / `a.` / `(1)` 原样）；前缀 = `"  ".repeat(depth) + markerText`, 悬挂缩进 = `displayWidth(prefix)`（天然含 pad 与前缀列, 子层续行对齐该层正文起列）。

## 偏差

- 设计如此, 无实现偏差。补充说明：列表判定仍逐行独立（无跨行状态）, 孤立缩进行按自身深度渲染、不做父子校验——与决策 2 一致。
- 其余范围外项（有序任务列表 `1. [ ]` / 定义列表）未实现, 与决策 1 一致。
