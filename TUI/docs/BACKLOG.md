## 待办

**#1 启动时终端尺寸过小警告**〔进行中: 2026-10-13〕（2026-10-13 登记）：**现象 / 现状** —— 终端尺寸过小时界面不可用，但没有任何提示（同次裁定：小尺寸**不做降级设计**；实测口径：宽 ≤ 30 列时活动区文字宽恒收敛到 8 列，`rows ≤ 4` 时内容区整体归零）。**期望** —— 启动时检测一次终端尺寸，**宽 ≤ 16 或 高 ≤ 9** 时用既有 `notice()` 弹一条警告（拟文案「终端尺寸过小（宽 ≤ 16 或高 ≤ 9），显示可能不可用，请调大窗口」）；**不监听 resize**。**落点**：`src/app/index.ts` 启动路径（取 `renderer.getSize()`）。**验收**：注入过小尺寸 → 启动后出现该提示；尺寸正常 → 不提示（两条用例）。**估时**：0.5-1 小时。**优先级**：P2。〔待办：2026-10-13 登记〕

**#2 重新设计回合区工具块的显示格式**〔进行中: 2026-10-13〕（2026-10-10 用户提出）：**现象 / 现状** —— 回合区（活动 pane）里工具调用与结果按「调用行（无标记）+ 结果行（`✓` / `✗` + detail）」平铺：看不出调用与结果的配对，批次边界只靠 step 头，失败与成功的视觉权重接近；参数只显示 adapter 启发式抽出的**单个**关键字段（path / command 等）。**期望（形制已逐条裁定，2026-10-13）** —— 工具 box 内继续拆：**名字 box + 每个参数一个 box + 结果 box**；名字行 = `标记 + 空格 + 工具名`（标记 `●` / `○` 黄、固定 1 toggle/s 墙钟相位；完成 `✓` 绿 / `✗` 红；无结果收场 `■` 灰）；参数行缩进 4、`名 值` 单空格**不对齐**；参数值与结果均折行、**上限 5 行**（超出保留首尾 + `…`）；结果行缩进 2（对齐工具名）；静默工具不出结果行；长名时按「另起不亏行数才另起（缩进 6）」取舍；**小尺寸不做降级**（另见〈启动时终端尺寸过小警告〉）；`/collapse` 与 `/verbose` 暂时失效（另见〈重新设计活动区两个开关〉）。**落点**：`adapter/normalize.ts`（`toolParams`）、`pipeline/boxes.ts`（`toolBox` 改子树）、`pipeline/rows.ts`（三类行）、`pipeline/frame.ts`（kinds / owner 对齐）、`layout/build-box.ts`（样式与三类行渲染）、`layout.ts`（帧层相位标记 + 两个开关失效）、`content-rules.ts`（符号常量）。**验收**：新增 `tests/tool-block.test.ts`（在飞两相位 / 完成 / 失败 / 静默 / 5 行上限 / 名字截断 / 长名取舍 / 非 JSON 兜底 / 多结果配对 / 并发）+ 复核并**允许重冻**工具块帧断言（逐场景记明）+ `check` + `build` + 全量测试 + `bench` ±10%。**详见**追踪文档 `implementation/2026-10-13-tool-block-display.md`。**估时**：1-1.5 天。**优先级**：P2。〔进行中：2026-10-13 接取〕

**#3 重新设计活动区两个开关（`/collapse` 紧凑 与 `/verbose` 档位）**（2026-10-13 登记, **待细化：详细内容待开工时与用户讨论后再补**）：**现象 / 现状** —— 两个开关自 2026-10-13 起**暂时失效**：`/collapse on|off`（`activityCompact`：活动区条目压 1 行 + 省略号）与 `/verbose think|tool|step`（`activityVerbose`：输出内容档位）不再影响渲染（拼帧层恒按完整形态出图），两个命令只回提示、不改状态 —— 原因是〈重新设计回合区工具块的显示格式〉改版后，工具块变成「名字 / 参数 / 结果」三层多行结构，旧的两档语义（压 1 行、只留调用行）与它冲突，需重新设计。**期望** —— 重新设计这两档在新形制下的语义与命令面（例如：紧凑档压成什么粒度、档位是否区分「参数 / 结果 / 思考」分别显隐、命令是否合并成一个 `/activity` 入口）。**落点**：`src/app/layout.ts`（`buildTopRegion` 的 render opts 与标题栏 verbose 指示）、`src/app/layout/build-box.ts`（`compact` / `actLevel` 分支）、`src/app/index.ts`（两个命令处理）、`state.ts`（`activityCompact` / `activityVerbose` 字段与 reducer）。**验收**：待细化（新语义确定后补：两档各自的行数 / 内容断言 + 命令面断言）。**估时**：待细化（初判 0.5-1 天）。**优先级**：P2（暂时失效期间功能缺失）。〔待办：2026-10-13 登记〕
