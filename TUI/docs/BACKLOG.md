**#1 相位符号闪烁引发版面抖动（边框左右跳 + 会话区上下跳）**〔缺陷: 2026-10-13 登记〕（2026-10-13 用户实测）：**现象 / 现状** —— 相位符号在实心 / 空心之间切换时**不止符号本身变化**：① 边框（活动区与会话区的外缘框列 / 分隔竖线）**左右跳动**；② **会话区**（历史 pane）的闪烁还会让整个会话区**上下跳动**。**期望** —— 相位切换只改符号字形，**帧几何与行数逐项不变**（同一列、同一行数、边框列不动、pane 顶边不动）。**复现** —— 真机 `dsh --profile fff`：让某回合处于运行中（用户块首行符号与工具名字行进入在飞相位），盯住 pane 边框列与会话区顶部。**疑似范围** —— ① 两条相位改写路径：`src/app/layout.ts` 的 `markToolNameRows()`（工具名字行整格改写，2026-10-13 新增）与 `userBlockSymbolResolver()`（用户块首行符号）；② 符号列宽是否恒为 1 显示列（`●` / `○` / `■` / `✓` / `✗` / `△` / `?` 混用时，若某个字形落进 `charWidth` 的**实测宽度**回退路径，该行总宽变化 → 右缘框列右移一列）；③ 上下跳：帧内容行数是否随相位变化（折行按符号宽度算 / `activityMaxScroll` 或窗口组数随之变化 → pane 顶边漂移）。**落点**：待定位（先真机复现 + 帧断言钉住）。**验收**：新增用例断言「相位 0 与相位 1 两帧的**几何与行数逐项相等**，仅首列字形不同」（活动区、会话区各一条）。**估时**：0.5-1 天（含定位）。**优先级**：P1（用户可见的版面抖动）。〔待办：2026-10-13 登记〕
