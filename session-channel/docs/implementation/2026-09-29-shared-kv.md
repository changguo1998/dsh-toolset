# 跨会话共享 KV（接取条目：`docs/BACKLOG.md`「扩展状态同步」）

状态：规划　　开启：2026-09-29
本文件是本任务唯一的过程记录与文档变更落点；计划外的文件不改。

## 目标

在 session-channel（#30 通道）之上提供**跨会话共享 KV**：last-value 语义 + 单调版本号，供插件做状态同步（多 dsh 进程 / 多会话共见）。含服务面读写与 CAS（`expectedVersion`）防丢更新；不引入新依赖（复用专用 Redis）。

## 调研

（来源：本仓源码）

- 现有键位（`src/keys.ts`）：`meta` / `alive:*` / `alias:*` / `inbox:*` / `cursor:*` / `ack:*`，统一 `dsh:session-channel:` 前缀；`SCHEMA_VERSION = 1`（本任务只新增键类，向后兼容，不递增）。
- 服务面：`apply()` 里手工列举（`peers/send/inbox/aliasSet/aliasList/aliasClear/status`），D5 已加**键集合守卫测试**——新增 `kv*` 方法必须同步 `SERVICE_FACE_METHODS`，否则测试失败。
- 写入风格：broker 层抛 `SessionChannelError`（稳定错误码）；服务层 catch 后返回 `{ok:false,error}`；别名类返回 `{ok, error, ...}`。
- 依赖：`redis` v4 客户端（`client.eval` 可用）——版本号自增与 CAS 用单条 Lua 脚本保证原子。
- `#30` 关闭时的范围外条目即本条（`docs/archived/2026-09-29-cross-session-intercom.md` 收尾记录）。

## 决策

- **数据结构**：`<prefix>kv:<key>` → JSON `{ value, version, updatedAt }`；版本号存于独立键 `<prefix>kvver:<key>`（`INCR`，全局单调，不与 payload 的键空间混淆——`kv:*` 扫描不会命中版本键）。
- **写入语义**：last-value（后写覆盖）；`opts.expectedVersion` 提供时做 CAS，不匹配 → `{ok:false,error:"kv_conflict",current}`；`opts.ttlSec` 可选过期。
- **原子性**：单条 Lua 脚本内完成「读旧版本 → CAS 校验 → INCR 版本 → SET payload」。
- **校验**：键 `[A-Za-z0-9_.-]{1,64}`；值须 JSON 可序列化且 UTF-8 ≤ `maxTextBytes`（缺省 8192）；越界返回稳定错误码。
- **删除**：`kvDelete` 同时删 payload 与版本键（版本随键删除归零，文档说明）。
- **范围**：只做服务面（插件状态同步）；**不做** agent 工具 action（按需另立条目）、不做订阅/通知（last-value 拉取）、不做跨机。
- 错误码新增：`kv_key_invalid` / `kv_value_invalid` / `kv_value_too_large` / `kv_conflict`（`SessionChannelErrorCode` 扩展）。

## 规划

计划改动文件清单：

1. `session-channel/src/keys.ts`：`kvKey` / `kvVersionKey` / `KV_PATTERN` / `KV_KEY_RE`。
2. `session-channel/src/types.ts`：`KvEntry` / `KvPutOptions` / `KvSetResult` / `KvDeleteResult` 与错误码扩展、配置注释。
3. `session-channel/src/broker.ts`：Lua 常量 + `putKv` / `getKv` / `listKv` / `deleteKv`。
4. `session-channel/src/index.ts`：服务类 4 方法（连接守卫 + 错误包装）、`SERVICE_FACE_METHODS` 增 4 键。
5. `session-channel/tests/broker.test.ts`：broker 级（版本自增、CAS 冲突、TTL、list/delete、键校验）。
6. `session-channel/tests/service.test.ts`：服务级 + 双实例（A 写 B 读）跨会话可见性。
7. `session-channel/README.md`：服务方法表 + 键位表 + 能力说明。
8. 本追踪文档。

明确不做：工具 action；变更订阅 / 通知；跨机同步；payload 加密。
