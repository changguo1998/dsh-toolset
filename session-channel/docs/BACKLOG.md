## 2. 功能

**自动别名：词表纳入自然科学类词, 后缀改为纯词名占满才兜底**

- 现状：自动别名恒为 `<前缀><词>-<4 位 hex>`（`src/alias-words.ts` 的 `autoAliasCandidate` / `pickAutoAlias`；`docs/DESIGN.md` §3.1）：hex 后缀每次必拼。词表 578 词（动物 / 植物 / 矿物岩石 / 天体 / 天气 / 自然地貌 / 天象），约束 ≤8 字符、`[A-Za-z]`、非保留字、无重复。
- 期望：(1) 词表可纳入**自然科学类**词（新增类别），约束维持 ≤8 字符、`[A-Za-z]`、非保留字、无重复，音节数不设限。(2) 自动别名默认只拼 `<前缀><词>`，**仅当该前缀的纯词名全部被占用时**才拼 `-<hex4>` 兜底。
- 裁定（2026-10-27 用户）：① 自然科学类词可用；② 音节约束不采用, 只保 ≤8 字符；③ hex 后缀兜底口径 = 该前缀纯词名全占满后启用。
- 落点：`src/alias-words.ts`（词表扩容 + 命名 / 候选逻辑）、`tests/alias.test.ts`（词表规模 / 取名 / 候选序列用例）、`docs/DESIGN.md` §3.1、`README.md` 的别名条（`:131`）。
- 验收：该包 `test` 全绿；新分配的自动别名默认无后缀；该前缀纯词名占满后才回落带后缀形态；既有旧格式别名为历史数据、不迁移。
- 来源：用户 2026-10-27 会话内裁定。状态：未开始。优先级：中。
