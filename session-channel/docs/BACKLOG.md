## 2. 功能

- **待办** **F1 会话别名自动生成**（≤8 字符名词性单词或名字）：
  - **现状**：别名目前只能显式 `alias set`；会话默认无别名（状态栏不显示别名段，`send` / `channel_delegate` 只能靠会话 id 或 `cwd:` 寻址）。
  - **期望**：会话启动时**自动生成**别名——**长度 ≤ 8 字符**、**名词性单词或名字**（如 `otter`、`lyra`）；与既有别名及保留字去重（仍走 `[A-Za-z0-9_-]{1,32}` 校验），可被 `alias set` 覆盖。
  - **接取时裁定**：词源（内置名词 / 名字表）、生成时机（`apply` 启动即写 / 首次用到时）、本地会话 id 的来源、是否随会话结束清理。
  - **落点**：`session-channel/src/index.ts`（别名键自动写入）+ `tests/`（词长 / 去重 / 覆盖用例）。
  - **验收**：新会话无需手工设置即有 ≤8 字符名词性别名；冲突自动重试；`alias list` 可见；`alias set` 可覆盖。
  - **来源·状态·优先级**：用户 2026-10-01 口述；待接取。优先级 P2。
